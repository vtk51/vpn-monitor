# VPN Monitor

Компактный нативный монитор сети для Windows x64, написанный на Go/Win32/GDI.
Работает без консоли, браузера, установки Go и внешних runtime-библиотек.
Это средство диагностики, а не VPN-клиент.

## Скачать

После публикации первого стабильного релиза:
[vpn-monitor.exe](https://github.com/vtk51/vpn-monitor/releases/latest/download/vpn-monitor.exe).
Для конкретной неизменяемой версии используйте ссылку вида
`https://github.com/vtk51/vpn-monitor/releases/download/v1.0.0/vpn-monitor.exe`
(тег — пример; не заменяйте уже опубликованные теги и файлы релиза).
Имя бинарника всегда `vpn-monitor.exe`; версия задаётся тегом, не именем файла.
До создания релиза эти ссылки могут возвращать 404.

Программа **не подписана цифровой подписью**. Windows SmartScreen может
предупредить о неизвестном издателе. Каталог EXE должен быть доступен для записи лога.

## Возможности

- Статусы и длительность реальных ICMP/DNS-проверок, минутный график YouTube.
- Компактное окно 380×353 логических пикселя; раскрываемый журнал на 200 событий.
- Булавка «Поверх окон» (по умолчанию выключена), пауза, подробный журнал.
- Таймаут 1–60000 мс (по умолчанию 2000), применяется к следующей отдельной пробе.
- Счётчик отдельных эпизодов сбоя YouTube: первый сбой и новый сбой после
  восстановления увеличивают его; повторные неуспешные пробы — нет.
  На паузе счётчик и состояние эпизода заморожены; начатая проба может завершиться.
- Встроенная многоразмерная иконка: отдельный файл ICO при запуске не нужен.

### Проверяемые узлы

| Узел | Проверка |
|---|---|
| Debian | ICMP `192.168.1.107` |
| Router | ICMP `192.168.1.100` |
| Yandex | ICMP `77.88.44.242` |
| YouTube | ICMP `192.178.24.110` |
| DNS | IPv4-запрос `youtube.com` через `192.168.1.107:53` |

Адреса заданы в исходниках (`worker_windows.go`), это исходная конфигурация,
а не универсальные адреса для любой сети. При адаптации проверьте также
текст сообщения в `monitor.go`. Проверки последовательные; после цикла пауза 1 секунда.
Таблица показывает последние отдельные результаты, не атомарный снимок цикла.
**ICMP к заданному IP не доказывает доступность сайта, видео или VPN**;
адреса сервисов могут измениться, а ICMP может фильтроваться.

`vpn-diag.log` рядом с EXE дописывается только после завершённых циклов
с отрицательным ICMP-результатом YouTube. Другие сбои сами по себе не создают
записи; подробность экранного журнала на это не влияет. Пустой лог может
создаваться при запуске; автоматической ротации нет. Ошибка ICMP-инициализации
или записи лога останавливает мониторинг и отображается в журнале.

Таймаут, счётчик, положение окна и режим «Поверх окон» **сбрасываются при
перезапуске**. Окно не растягивается; перенос между мониторами с разным DPI
и полноценная поддержка экранных дикторов не заявлены. График содержит только
реальные результаты за последнюю минуту, с разрывами при сбоях.

## Сборка

Windows x64 и установленный Go 1.22+ в `PATH` (рекомендуется поддерживаемый Go):

```bat
build.cmd
```

Скрипт выполняет тесты без кеша, `go vet` и создаёт **vpn-monitor.exe**:

```bat
set GOOS=windows
set GOARCH=amd64
set CGO_ENABLED=0
go test -count=1 -v ./...
go vet ./...
go build -trimpath -ldflags="-H=windowsgui -s -w" -o vpn-monitor.exe .
```

Внешних Go-зависимостей нет. **`resource_windows_amd64.syso` должен оставаться
в репозитории**: Go автоматически включает его в EXE. Для пересоздания ресурса
из `app.ico` — `regenerate-resources.cmd` (закреплённый `rsrc@v0.10.2`).
Для изменения рисунка: Python с Pillow, `python generate_icon.py`, затем
пересоздание ресурса. Эти инструменты не нужны пользователям готового EXE.

## Проверка и выпуск

Go-тесты включают настоящий Windows ICMP loopback и локальный UDP DNS-сервер;
они не требуют доступности перечисленных выше удалённых узлов.
Локальные GUI-проверки требуют интерактивный рабочий стол Windows, Python и Pillow:

```bat
python icon_verify.py ./vpn-monitor.exe
python compact_verify.py ./vpn-monitor.exe
```

Первый скрипт — короткая проверка настоящего окна, PE-ресурсов, иконок,
таймаута, паузы/продолжения и корректного закрытия. Второй — расширенная
сетевая проверка; она зависит от реальной сети, в том числе сбоя при 1 мс
и восстановления. Скрипты создают локальные снимки/JSON рядом с EXE;
эти файлы и логи исключены из Git. Дополнительная проверка мыши/подсказки:
`python mouse_tooltip_verify.py ./vpn-monitor.exe`.

Actions на `windows-latest` выполняет тесты, vet и сборку при push/PR,
сохраняет артефакт с `vpn-monitor.exe`. Push тега `v*` после успешной сборки
создаёт GitHub Release с тем же именем EXE через GitHub CLI. Только задача
релиза получает `contents: write`; внешние Actions закреплены полными SHA.
GUI-скрипты в CI не запускаются. Первый удалённый запуск CI нужно проверить
после публикации; локальная сборка не является доказательством успешного CI.

Лицензия пока не выбрана; файл лицензии намеренно не добавлен.
